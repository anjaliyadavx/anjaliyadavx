# Retail Sales Analysis

## 📊 Project Overview
This project analyzes retail sales data to understand sales performance, customer behavior, product categories, and monthly sales trends.

The project was developed using Python in Google Colab and Power BI for data visualization and dashboard creation.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Power BI
- Excel

## 📌 Project Objectives
- Analyze overall retail sales performance
- Compare sales across product categories
- Analyze sales by gender
- Identify monthly sales trends
- Calculate and understand profit
- Create an interactive Power BI dashboard

## 📈 Dashboard
The Power BI dashboard provides visual insights into:
- Total Sales
- Total Profit
- Sales by Gender
- Sales by Category
- Monthly Sales Trends
- Category filtering

## 🔍 Key Insights
- Total sales are approximately 912K.
- Total profit is approximately 721.96K.
- Electronics and Clothing show strong sales performance.
- Sales increase significantly during the later months of the year.
